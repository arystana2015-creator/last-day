# Последний день — калькулятор увольнения по собственному желанию

Учебный проект по вайбкодингу. Сайт считает по Трудовому кодексу Республики Казахстан:
- когда истекает срок уведомления при увольнении по собственному желанию (ст. 13, 56 ТК РК);
- до какого дня работодатель обязан произвести окончательный расчёт (ст. 113 п. 4 ТК РК).

Сайт — обычные HTML, CSS и JavaScript, без сервера. Введённые даты никуда не отправляются.

Справочная информация, не заменяет консультацию юриста. Содержание проверено на 05.11.2026.
